# Práctica Semana 7

Aplicación para registrar y consultar empleados utilizando JavaFX y PostgreSQL.

## Funciones

- Registrar empleados.
- Mostrar empleados en una tabla.
- Limpiar el formulario.
- Actualizar la tabla.

## Cómo ejecutar

1. Abrir PostgreSQL en pgAdmin.
2. Ejecutar `CREATE DATABASE biblioteca_fx;` si la base de datos todavía no existe.
3. Abrir la base de datos `biblioteca_fx` y ejecutar el resto de `PracticaSQL/base_datos.sql`.
4. Revisar la contraseña en `DatabaseConnection.java`.
5. Abrir `PracticaSQL` en IntelliJ IDEA.
6. Ejecutar `RegistroEmpleadosApplication.java`.
